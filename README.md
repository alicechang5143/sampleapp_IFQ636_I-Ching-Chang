**Event Booking System**

#Description:

This is a full-stack web application for booking event rickets. Users can register, log in, log out, and manage their booking through a simple and intuitive interface.

---

# Technology Stack
-Fronted: React
-Backend: Node.js, Express
-Repository: MongoDB Altas
-Authentication: JWT
-Version Control: GitHub

---

#Function

-User register, login, and logout
-JWT authentication
-Booking CRUD(Create, Read, Update, Delete)

-backend/
